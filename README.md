# Professional Portfolio Website

A modern, high-end professional developer portfolio website built with React, Vite, and Tailwind CSS. This portfolio is designed to be recruiter-friendly, client-oriented, and production-ready.

## 🚀 Features

- **Dynamic Hero Section**: Interactive animations and engaging introduction.
- **Project Showcases**: Detailed display of projects (MERN Stack, etc.) with images and descriptions.
- **Experience Timeline**: Professional career path and responsibilities.
- **Skills Matrix**: Categorized technical skills (Frontend, Backend, Tools) with modern UI.
- **Interactive Contact Form**: Functional "Get In Touch" section with validation.
- **Modern Animations**: Smooth scrolling and reveal animations using Framer Motion.
- **Fully Responsive**: Optimized for all devices and screen sizes.
- **Dark Mode Aesthetics**: Sleek, professional design with a curated color palette.

## 🛠️ Tech Stack

- **Frontend**: [React.js](https://reactjs.org/) (Vite)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Scrolling**: [React Scroll](https://www.npmjs.com/package/react-scroll)
- **Notifications**: [React Toastify](https://fkhadra.github.io/react-toastify/)

## ⚙️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
